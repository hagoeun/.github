## 🌙 컨셉
밤이 되면 깨어나는 공룡들과 함께  
식물에 담긴 추억을 수집하는 힐링 탐험 게임

## 📖 소개
주인공 **베리(Berry)** 는 공룡 친구들의 의뢰를 받아  
각자의 추억이 담긴 식물을 찾아줍니다.

플레이어는 식물을 탐색하고 채집하며  
그 안에 담긴 이야기를 수집하게 됩니다.

수집한 식물과 이야기는  
다이어리와 식물도감에 기록되고 자유롭게 꾸밀 수 있습니다.

## ✨ 특징
- 공룡 의뢰 기반 탐험 및 채집
- 식물 + 스토리 수집 시스템
- 다이어리 커스터마이징
- 실제 식물 기반 도감 콘텐츠

## 🎯 한 줄 소개
공룡과 함께, 식물에 담긴 추억을 모으는 밤의 힐링 게임
